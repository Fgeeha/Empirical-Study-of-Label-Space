# Pipeline ECCV 2026 -- порядок запуска

Полный pipeline автоматизирован в `12.1_full_pipeline.sh` (165 шагов, 8 фаз).
Ниже описан как автоматический, так и ручной порядок.

---

## Быстрый старт

```bash
# Полный прогон (все 8 фаз)
bash scripts/12.1_full_pipeline.sh

# Посмотреть что будет запущено (без выполнения)
bash scripts/12.1_full_pipeline.sh --dry-run

# Конкретная фаза
bash scripts/12.1_full_pipeline.sh --phase 2

# Продолжить с фазы N
bash scripts/12.1_full_pipeline.sh --from 5

# Диапазон фаз
bash scripts/12.1_full_pipeline.sh --from 4 --to 6

# Указать Edge-Bench сервер
bash scripts/12.1_full_pipeline.sh --server http://192.168.1.4:8000
```

Лог записывается в `logs/pipeline_YYYYMMDD_HHMMSS.log`.

## Фаза 1: Подготовка данных (~30 сек)

Сбор классов, построение shared label space (3 стратегии), фильтрация датасетов, сплиты.

```bash
bash scripts/12.1_full_pipeline.sh --phase 1
```

Ручной запуск:

```bash
# 1. Сбор классов из трех датасетов
poetry run python scripts/1.1_collect_classes_pv.py        # -> artifacts/classes_pv.txt (38 классов)
poetry run python scripts/1.2_collect_classes_plantdoc.py   # -> artifacts/classes_plantdoc.txt (28 классов)
poetry run python scripts/1.3_collect_classes_fcdd.py       # -> artifacts/classes_fcdd.txt (17 классов)

# 2. Shared label space (3 стратегии маппинга)
poetry run python scripts/2.4_build_shared_subset.py        # Fuzzy matching -> 16 классов
poetry run python scripts/2.5_build_shared_subset_sbert.py  # SBERT cosine -> 15 классов
poetry run python scripts/2.6_build_shared_subset_hybrid.py # Fuzzy + SBERT -> 18 классов

# 3. Фильтрация датасетов по маппингу
for s in hybrid Fuzzy sbert; do
  poetry run python scripts/3.1_filter_shared_subset.py --mapping configs/class_mapping_${s}.json
done

# 4. Сплиты PV (train/val/test)
for s in hybrid Fuzzy sbert; do
  poetry run python scripts/4.1_split_pv_dataset.py --strategy $s
done

# 5. Калибровочная выборка 10% (для PTQ)
for s in hybrid Fuzzy sbert; do
  poetry run python scripts/8.1_prepare_pv_calibration.py --strategy $s
done

# 6. Подготовка target (PlantDoc)
for s in hybrid Fuzzy sbert; do
  poetry run python scripts/5.1_prepare_target_test.py --strategy $s --target plantdoc
  poetry run python scripts/5.5.1_split_target_dataset.py --strategy $s --target plantdoc
  poetry run python scripts/6.2_prepare_target_unlabeled.py --strategy $s --target plantdoc
done
```

Артефакты:

```
configs/class_mapping_{Fuzzy,hybrid,sbert}.json
configs/label_map_{strategy}.csv
splits/{strategy}/pv_{train,val,test}.csv
splits/{strategy}/pv_calib_10pct.csv
splits/{strategy}/target_plantdoc_{test,train,val}.csv
splits/{strategy}/target_plantdoc_unlabeled.csv
```

## Фаза 2: Обучение моделей (GPU, часы)

5 архитектур x 3 стратегии = 15 baseline моделей + CORAL + fine-tune.

```bash
bash scripts/12.1_full_pipeline.sh --phase 2
```

Ручной запуск (пример для hybrid):

```bash
# Baselines (PV)
poetry run python scripts/4.2_train_resnet50_pv.py --strategy hybrid
poetry run python scripts/4.2b_train_efficientnet_pv.py --strategy hybrid
poetry run python scripts/4.2c_train_mobilenet_baseline_pv.py --strategy hybrid

# Edge-архитектуры
poetry run python scripts/9.0_train_mobilenetv2_pv.py --strategy hybrid
poetry run python scripts/10.6_train_mobilenetv1_pv.py --strategy hybrid
poetry run python scripts/10.8_train_efficientnet_lite0_pv.py --strategy hybrid

# CORAL (lambda sweep, ResNet-50)
for l in 0.01 0.1 1.0 10.0; do
  poetry run python scripts/6.3_train_coral.py \
    --strategy hybrid --target plantdoc --lambda_coral $l --epochs 20
done

# CORAL (MobileNetV2, лучший lambda)
poetry run python scripts/9.1_train_coral_mobilenetv2.py \
  --strategy hybrid --target plantdoc --lambda_coral 0.1 --epochs 20

# Fine-tune (верхняя граница)
poetry run python scripts/5.5.2_finetune_target.py --strategy hybrid --target plantdoc
```

Повторить для Fuzzy и sbert (lambda для sbert: 0.01).

Артефакты:

```
models/resnet50_pv_{strategy}_best.pt
models/efficientnet_pv_{strategy}_best.pt
models/mobilenet_pv_{strategy}_best.pt
models/mobilenetv2_pv_{strategy}_best.pt
models/mobilenetv1_pv_{strategy}_best.pt
models/efficientnet_lite0_pv_{strategy}_best.pt
models/resnet50_coral_lambda_{l}_{strategy}.pt
```

## Фаза 5: Квантизация и TFLite экспорт (CPU, десятки минут)

PyTorch -> Keras -> SavedModel -> FP32 TFLite -> INT8 PTQ TFLite.
5 архитектур x 3 стратегии = 15 INT8 TFLite моделей.

TF экспорт работает на CPU (`CUDA_VISIBLE_DEVICES=""`), т.к. TF 2.20 не поддерживает RTX 5070 Ti.

```bash
bash scripts/12.1_full_pipeline.sh --phase 5
```

Ручной запуск (пример для hybrid):

```bash
# Экспорт весов PyTorch -> .npz
poetry run python scripts/8.2a_export_torch_weights.py --strategy hybrid
poetry run python scripts/9.1a_export_mobilenetv2_weights.py --strategy hybrid
poetry run python scripts/10.1_export_efficientnet_weights.py --strategy hybrid

# ResNet-50: SavedModel -> FP32 -> INT8 -> T3 eval
CUDA_VISIBLE_DEVICES="" poetry run python scripts/8.2b_build_tf_savedmodel.py --strategy hybrid
CUDA_VISIBLE_DEVICES="" poetry run python scripts/8.3_export_tflite_fp32.py --strategy hybrid
CUDA_VISIBLE_DEVICES="" poetry run python scripts/8.4_export_tflite_int8.py --strategy hybrid
CUDA_VISIBLE_DEVICES="" poetry run python scripts/8.5_eval_tflite_quant.py --strategy hybrid
poetry run python scripts/8.6_plot_quant_tradeoff.py --strategy hybrid

# INT8 TFLite для EdgeTPU (все архитектуры)
CUDA_VISIBLE_DEVICES="" poetry run python scripts/10.4_export_tflite_int8_resnet50.py --strategy hybrid
CUDA_VISIBLE_DEVICES="" poetry run python scripts/9.2_export_tflite_int8_mobilenet.py --strategy hybrid
CUDA_VISIBLE_DEVICES="" poetry run python scripts/10.7_export_tflite_int8_mobilenetv1.py --strategy hybrid
CUDA_VISIBLE_DEVICES="" poetry run python scripts/10.9_export_tflite_int8_efficientnet_lite0.py --strategy hybrid
CUDA_VISIBLE_DEVICES="" poetry run python scripts/10.3_export_tflite_int8_efficientnet.py --strategy hybrid
```

Артефакты:

```
export/resnet50_tf_{strategy}/              # SavedModel
export/model_fp32_{strategy}.tflite         # FP32
export/model_int8_ptq_{strategy}.tflite     # INT8 (via SavedModel)
```

## Фаза 6: EdgeTPU компиляция (минуты)

Компилирует 4 EdgeTPU-совместимые архитектуры x 3 стратегии = 12 моделей.
EfficientNet-B3 пропускается (Swish + SE не поддерживаются EdgeTPU).

```bash
bash scripts/12.1_full_pipeline.sh --phase 6
```

Ручной запуск:

```bash
bash scripts/9.6_compile_edgetpu_models.sh
```

Требует `edgetpu_compiler` (установка: `sudo apt install edgetpu-compiler`).
Скрипт автоматически находит все `*_int8_ptq_*.tflite` в `export/`, пропускает уже скомпилированные.

Артефакты:

```
export/edgetpu/{arch}_int8_ptq_{strategy}_edgetpu.tflite   # 12 моделей
```

Матрица совместимости:

| Архитектура | Params | EdgeTPU | Причина |
|-------------|--------|---------|---------|
| MobileNetV1 | 3.2M | Da | ReLU6, DepthwiseSeparable |
| MobileNetV2 | 2.2M | Da | ReLU6, InvertedResidual |
| EfficientNet-Lite0 | 3.5M | Da | ReLU6, MBConv без SE |
| ResNet-50 | 23.5M | Da | ReLU, стандартные операции |
| EfficientNet-B3 | 10.8M | Net | Swish + SE blocks |

## Фаза 7: Edge-Bench -- загрузка, деплой и бенчмарки

Загружает модели на сервер Edge-Bench, деплоит на Raspberry Pi, создает эксперименты и ждет результатов.

```bash
bash scripts/12.1_full_pipeline.sh --phase 7
```

Ручной запуск:

```bash
# Полный цикл: upload -> deploy -> run -> wait
poetry run python scripts/9.9_run_edgebench.py \
  --server http://192.168.1.4:8000 \
  --runs 100 \
  --timeout 600

# Только загрузка (без экспериментов)
poetry run python scripts/9.9_run_edgebench.py --upload-only

# Проверить статус сервера и устройств
poetry run python scripts/9.9_run_edgebench.py --status
```

Предпосылки:
- Edge-Bench сервер запущен: `cd edge-bench && make server`
- RPi agent запущен: `cd edge-bench && make agent` (на Raspberry Pi)
- Coral USB Accelerator подключен к RPi (для EdgeTPU бенчмарков)

Скрипт создает 27 экспериментов: 5 архитектур x 3 стратегии, CPU + EdgeTPU.
Каждый эксперимент: 20 warmup + 100 benchmark итераций.

## Зависимости

- **GPU**: PyTorch + CUDA (фазы 2, 3, 4 -- обучение и инференс)
- **CPU**: TensorFlow 2.20 (фаза 5 -- TFLite export, `CUDA_VISIBLE_DEVICES=""`)
- **x86**: edgetpu_compiler (фаза 6)
- **Network**: Edge-Bench сервер + RPi agent (фазы 7, 8)

Все Python-зависимости управляются через `poetry` (`pyproject.toml`).

## Стратегии маппинга классов

| Стратегия | Метод | Классов | Использование |
|-----------|-------|---------|---------------|
| hybrid | Fuzzy + SBERT | 18 | Main results |
| Fuzzy | fuzzy string matching | 16 | Ablation |
| sbert | SBERT cosine similarity | 15 | Ablation |

Все эксперименты запускаются для всех трех стратегий.
Hybrid -- основная стратегия для таблиц и графиков в статье.
